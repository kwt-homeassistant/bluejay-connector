# 需求文档

## 目标

扩展 AITO Home Assistant 自定义集成，以只读方式获取并私有保存鸿蒙智行 App 已展示的最近一年行程摘要，为后续充电提醒提供可分析的历史样本，同时继续提供最近一程、今日和近 7 日聚合状态。

## 来源与上下文

- 用户确认问界 M8 在鸿蒙智行 App 中具有行车报告和行程记录页面，并提供页面截图作为字段与单位证据。
- APK `3.0.2.300` 的 Retrofit 与 ArkUI-X 字节码确认 `day-trip-range` 接口、日期格式和响应字段。
- 正式 Home Assistant 仍运行 AITO `0.3.0`；本轮只修改 fork、运行本地合成测试并提交开发分支。

## 范围

- 本轮包含：API 客户端、脱敏解析模型、最近 365 日私有持久化、30 天分批回填和断点续传、6 个业务摘要传感器、2 个归档进度传感器、合成测试、HACS 元数据和 README。
- 本轮不包含：正式 HA 升级或重启、真实账号接口调用、车辆控制、单次行程详情、起终点、轨迹坐标、Hermes 充电自动化。

## 验收标准

- [x] `day-trip-range` 生成正确的请求路径、查询参数和车辆请求头。
- [x] 合成响应可解析日期小计与单次行程字段，非法值不会变成真实 `0`。
- [x] coordinator 最多保留最近 365 日脱敏记录，空窗口也推进覆盖水位，重启后从覆盖缺口继续。
- [x] 最近一程、今日、近 7 日、更新时间、覆盖天数和回填进度共 8 个实体契约稳定。
- [x] 私有存储不含真实 `tripId`、坐标或未知字段，完整行程不进入实体 attributes、Recorder、diagnostics 或日志。
- [x] 14 项单元测试通过；最终 Python 编译、JSON、diff 和隐私门禁在提交前统一复核。
- [x] README 不再声称云端没有行程，并明确私有持久化、回填、隐私、失败和刷新语义。

## 约束与安全边界

- 风险等级：L2，本地云 API 和实体契约变更。
- 真实 HA 部署、服务重启、账号操作和车辆动作均为 L3 人工闸门。
- 不提交真实截图、完整响应、日期、里程、时间、速度、能耗、车辆 ID、VIN、坐标、Token 或 Cookie。
