# 执行计划

## 执行模式

- `execute-after-freeze + release`

## 阶段拆分

| 阶段 | 目标 | 非目标 | 验证 | 人工确认点 |
| --- | --- | --- | --- | --- |
| P0 | 冻结 API、字段、时区、隐私与失败契约 | 不调用真实账号 | 文档审查 | 无 |
| P1 | 实现 API 与纯 Python 解析模型 | 不接详情/坐标 | 单元测试 | 无 |
| P2 | 接入 coordinator、365 日持久化回填与 8 个实体 | 不部署 HA | 合成测试、编译 | 无 |
| P3 | README、HACS 元数据、预发布审计和分支推送 | 不创建 Release | 全部门禁 | push 仅限既定 fork |
| P4 | 正式 HA 升级与真实响应验收 | 不触发车辆控制 | HA 回归 | 用户已明确授权 |
| P5 | 远端仓库改为中性代号并更新引用 | 不改变 PUBLIC/fork/正式 HA | GitHub API、manifest、Git remote、文档门禁 | 用户已明确授权改名 |
| P6 | 修正 AC/DC 充电遥测并发布 `0.4.2` | 不调用车辆控制 | 合成测试、正式充电实体回读、失败自动回滚 | 用户已明确授权正式部署与 Core 重启 |

## 停止条件

- 响应契约与 App 证据冲突。
- 需要输出真实账号、Token、车辆标识、截图或行程数据。
- 需要正式 HA 写入、重启、HACS 升级或车辆动作但未授权。
