# 发布说明

## 变更内容

- AITO `0.4.2` 包含 `0.4.0` 的能耗周期实体、最近 7 日低频刷新和最近 365 日历史行程私有归档。
- 修复直接 HTTP 响应的顶层行程数组解析，并兼容 App 原生桥接层的包装结构。
- 修复 M8 实时充电状态：与 App 一致取 AC/DC 状态最大值，并支持未充电、已连接、故障、充电、停止、预热和预约等待。
- 修复充电电流和功率：充电中选择实际 AC/DC 通道电流，非充电状态清零，旧通用字段保留兼容回退。
- 契约失配日志只记录容器类型和白名单字段名，不记录响应值或未知键名。
- 首次配置按 30 天窗口后台回填，每批成功即持久化，重启后从日期覆盖缺口继续。
- 新增最近一程里程/时间/时长、今日里程、近 7 日里程、报告更新时间、覆盖天数和回填进度共 8 个实体。
- 完整行程仅以脱敏模型保存在 coordinator 内存与 HA 私有 `.storage`，不进入实体 attributes、Recorder、diagnostics 或日志。
- 新增 HACS 元数据、合成 fixture 和单元测试；Actions 工作流因现有 OAuth 缺少 `workflow` scope 暂未纳入。
- 公开 fork 使用中性代号 `bluejay-connector`，manifest 文档和 Issue 地址同步更新；识别性 Topics 已清空，Custom Property 分类保留。

## 发布策略

- 先提交并 push 固定开发分支候选，不创建 GitHub Release。
- 新建版本化组件目录备份后，在用户已授权范围内手动替换正式 HA 组件；Core 检查或发布后实体验收失败时立即恢复备份。

## 回滚

- 源码候选：回退本分支提交。
- 正式环境：恢复本次部署前的 `/config/.codex-backups/aito-pre-0.4.2-*`，重新运行 Core 检查与重启；完整 HAOS 备份 `06cce438` 只作为更深层回滚点。

## 剩余风险

- 未公开云 API 可能变化。
- 历史行程尚未用真实响应验证时区、空数据和跨月范围。
- 充电遥测虽与 App 字节码一致，仍待正式充电中的实体回读确认。
- 正式 HA 运行时与 Recorder 长期统计尚未验收。
- 改名不能隐藏 GitHub fork 关系、旧 URL 重定向、公开代码内容或搜索引擎缓存。
